# Oksaesthetic

Лендинг камерной студии эстетики: уход за кожей, перманентный макияж, лазер и IPL. Три языка (RU / ES / EN) с переключателем.

- `index.html` — лендинг (статичный, без сборки)
- `logo.html` — три варианта логотипа; выбран вариант A «Классика»
- `assets/` — логотип (SVG, светлый и тёмный) и favicon

Тексты в квадратных скобках — заглушки: цены, имя мастера, контакты, отзывы, фото.

Чтобы опубликовать через GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.
